# Habits

Track your daily habits here. Each task is tagged `#habit` and has a `🔁 every day` recurrence rule so Task Manager's habit tracker recognises it.

Check off each habit when you complete it. The sidebar **Habits** tab will show a 14-day heatmap and current streak for each one.
