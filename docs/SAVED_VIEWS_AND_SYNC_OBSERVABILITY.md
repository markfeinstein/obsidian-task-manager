# Saved views and sync history

## Saved view presets

Task Manager supports saved table filters and Kanban boards. Manage them in settings to reuse a view without rebuilding its configuration. Existing table and Kanban settings remain available when presets are updated.

## Sync history

Recent sync runs appear in **Settings → Sync** and Diagnostics. Each entry can include the service, start and end times, outcome, counts, and details. Outcomes include success, dry-run, partial, and failed.

Use **Open sync conflict report** to review conflicting fields. Choosing a resolution does not itself guarantee that the provider was updated; review the next sync result. See [Sync reconciliation](SYNC_V2_CONTRACT.md).
